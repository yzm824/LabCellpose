Quantification method

Mean intensity is calculated from original pixels in each cell mask. Background-corrected mean = cell mean − the selected background estimate for that field and channel. Both the background mean and median are recorded; the method can be changed in the results without re-segmentation. Background excludes the segmented objects, bright pixels in the chosen reference channel, and a surrounding margin. Check the background overlay in the results. Dense fields or unusual staining may need different settings.

The result page also shows an inner edge and an interior region. These are geometric regions, not identified plasma membranes, nuclei, or Golgi. Negative corrected values are retained. Unequal exposure/gain and saturated images require interpretation before comparing samples.

Segmentation and measurement parameters

A GPU failure is reported rather than silently rerun. You can select CPU and start a new run. Cellpose enlarges each image by 30 / cell diameter before segmentation, so time and memory grow quickly for small diameters; a run is refused when the enlarged image would exceed 8192 × 8192 pixels.

Analysis presets

Reuse channel assignments and analysis parameters for images acquired with the same protocol. Image selection and output directory are not saved. Review channel assignments after loading.
