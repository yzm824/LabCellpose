LabCellpose 1.0 — Apple Silicon Mac app

Desktop application developer: Zhenmo Yu.
Cellpose and dependencies retain their original authorship and licenses.

Use without Claude, Codex, Terminal, or a separate Python installation.
Keep the .app intact. You may move it to Applications or another local folder.

1. Double-click LabCellpose.app.
2. Choose a TIFF, ZIP, or image folder. Start with one representative field.
3. Name the channels and select one segmentation channel and the fluorescence
   channels to measure. Confirm the page order and channel roles.
4. Choose a result folder and click Run analysis.
5. Review the interactive results that open in your default browser.
   Exclude unwanted cells, then click Download included CSV.

Save settings to reuse an experiment setup. Settings do not identify stains or
cell types automatically. Use the Ryu preset only for the matching five-channel
experiment. Different channel counts are supported; ambiguous Z/time stacks
must not be treated as channels. This release accepts aligned 2D grayscale
uint8/uint16 TIFF pages, not native CZI/ND2/LIF, RGB composites, or 3D/time-series
analysis. Separate per-channel files must first be combined into registered
multichannel TIFF stacks. Start with a small batch: selected images and result
previews are held in memory.

Results and manual review
The viewer is generated automatically by the program, without an LLM. Display
channel and measurement channel are independent. Auto display contrast varies
by field/channel; choose Fixed to compare the same channel across fields.
Changing display contrast does not change measurements from the original pixels.
Corrected mean = cell-region mean - the channel's background median, computed
outside cell masks and bright foreground with a margin. Inspect the background
overlay. Negative values are retained. Matching display contrast does not correct
exposure, gain, illumination, saturation, or batch differences.
Whole cell, inner-edge and interior measurements are geometric regions. This
release does not identify nuclei, Golgi, or the plasma membrane biologically.

The original measurements.csv includes all candidates. Only Download included
CSV applies manual exclusions. Save QC decisions JSON to preserve/share your
review; browser storage can be cleared or change if the local port changes.
Use Open saved results to reopen a completed run folder or its results subfolder.
Keep the app running while viewing results. Quitting stops its local server.
Every analysis creates a new folder. Stop keeps partial output; retry creates a
new run and does not overwrite earlier results. A failed GPU run can be retried
with Processing device = CPU in Advanced settings.

Compatibility and status
Apple Silicon (ARM64), macOS 14 or later is the build target. Tested on one
Apple Silicon Mac running macOS 27.0.1; other Macs/OS releases are not yet tested.
This is a research pilot, not a validated turnkey assay or an App Store release.
The app has a local ad-hoc signature, not Apple Developer ID notarization.
A downloaded copy may be blocked by macOS. Do not disable system-wide security;
have a trusted developer review/sign/notarize it for broader distribution.

All analysis is local. No lab images, API keys, user settings, or results are
included in this distribution. The large download is the bundled scientific
runtime and Cellpose model, needed for offline execution. No cloud service,
subscription, or LLM account is required.

Frozen engine: LabCellpose 0.3.0, Cellpose 4.2.1.1, cpsam_v2, Python 3.12.14.
The desktop wrapper is 1.0; engine manifests retain their 0.3.0 version.
The original engine methods, version locks, license notices and checksums are
inside LabCellpose.app/Contents/Resources/payload/. Third-party licenses remain
with the corresponding components. Each run records configuration, source
identity, versions, model hash, validation, masks and measurements.
