LabCellpose 1.0 packages the local Cellpose workflow as an Apple Silicon Mac app.
Developed by Zhenmo Yu.

Choose multichannel TIFF images, confirm segmentation and measurement roles, run
locally, and review results in your browser. Manual exclusions apply to the
included-measurements CSV. The app bundles Python, Cellpose, and model weights;
no AI agent or separate runtime setup is needed.

Download **LabCellpose-1.0-mac-arm64.zip** and extract it. The automatic Source code
archives are not the runnable app. See README.txt inside the ZIP for usage.

Research pilot, tested on one Apple Silicon Mac (macOS 27.0.1). Ad-hoc signed;
not Apple Developer ID signed or notarized. Other Macs have not been tested.
