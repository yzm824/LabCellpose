Methods and interpretation

Scope

Each segmentation input produces an independent object population; object IDs are not matched between inputs. Cellpose outputs object regions; a complete run does not establish cell identity or segmentation accuracy. No nuclear/perinuclear analysis, image registration, exposure normalization or biological statistical tests are performed.

Background estimation

Use Background above the image to inspect the exact sampled region. A sufficient number of pixels does not prove that region is free of fluorescence. The same background estimate is applied to all segmentation inputs within each image.

Measurements

Corrected mean = original ROI mean − selected field/channel background estimate. Corrected integrated intensity = raw sum − area × the selected background estimate. Negative values are retained. Empty regions and invalid background corrections are missing. Saturated counts use the recorded limit, when known. Saturation flags indicate censored intensities.

Regions and display

Auto contrast uses field/channel p10–p99.9 with an asinh transform. Fixed contrast uses a shared linear range within each channel across this run. Display contrast, colours, merged channels and resized previews never enter measurement. Equal display scales do not correct unequal exposure or gain.

Review

Flags (edge, unusually small or large, saturated) are hints for the reviewer: nothing is excluded automatically, and unmarked cells have not necessarily been reviewed. Size flags mark objects more than three scaled median absolute deviations from the median log area of the run and at least a factor of two from the median area. The plot shows included cells only; it is a review aid, not a statistical test. Blind review hides file names and conditions and shows the images in a fixed shuffled order.

Acquisition metadata

Filter names, wavelengths and display colours do not establish fluorophore, construct or organelle identity. Biological labels require researcher confirmation.

Export

The exported table uses the contents chosen in the Export step (all columns, key values, one row per cell, a table by condition, or a custom selection) and leaves out every excluded cell. Display and measurement selectors on this page do not restrict the export. Exported values are the same numbers in every layout; choosing contents only selects and arranges them. Background used is the estimate subtracted for corrected values; each channel uses one estimator across all images. Conditions are the folders that hold the images. The original measurements.csv retains all objects and the initial run settings. Review decisions can be saved or restored as a file. Source and model checksums, configuration, versions, masks and validation results are saved beside this report. This page performs no new inference and does not upload images.
