Methods and interpretation

Scope

Each segmentation input produces an independent object population; object IDs are not matched between inputs. Cellpose outputs object regions; a complete run does not establish cell identity or segmentation accuracy. No nuclear/perinuclear analysis, image registration, exposure normalization or biological statistical tests are performed.

Background estimation

Use “Show background” to inspect the exact sampled region. A sufficient number of pixels does not prove that region is free of fluorescence. The same background estimate is applied to all segmentation inputs within each FOV.

Measurements

Corrected mean = original ROI mean − selected field/channel background estimate. Corrected integrated intensity = raw sum − area × the selected background estimate. Negative values are retained. Empty regions and invalid background corrections are missing. Saturated counts use the recorded limit, when known. Saturation flags indicate censored intensities.

Regions and display

Auto display uses field/channel p10–p99.9 with an asinh transform. Fixed display uses a shared linear range within each channel across this run. Display contrast and resized previews never enter measurement. Equal display scales do not correct unequal exposure or gain.

Acquisition metadata

Filter names, wavelengths and display colors do not establish fluorophore, construct or organelle identity. Biological labels require researcher confirmation.

Export

Optional ratios are exploratory display-only values; the CSV exports their underlying intensities. The included CSV uses the export segmentation scope in the export dock and excludes every row of manually excluded objects. Display and measurement selectors do not restrict exported measurement channels or regions. The included CSV records the chosen background estimator and both background values. Each channel uses one estimator across all FOVs. The original CSV retains all objects and the initial run settings. QC decisions and background settings are local to this viewer and can be saved or restored as JSON; unmarked objects have not necessarily been reviewed. Source and model checksums, configuration, versions, masks and validation results are saved beside this viewer. This page performs no new inference and does not upload images.
